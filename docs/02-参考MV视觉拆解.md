## 1. 第一印象：玩具、复制与故障

官方封面是一颗**粉色塑料大脑**放在白色瓷盘上，像被拍成微距静物。

它给出了三个关键词：

1. **玩具感**：塑料、陶瓷、微距、柔光，不是写实生物。
2. **病理感 / 复制感**：大脑、盘子、标本；标题里的“复制复制复制复制我”把“我”变成可量产的对象。
3. **极简底色**：白 / 灰背景，只允许一个高饱和强调色（粉）。

首帧则切到另一种语言：黑底、白色手绘线稿、头发下露出的**彩虹故障大脑**。

这两种语言交替出现：**3D 塑料静物** ↔ **2D 手绘线稿**；**白** ↔ **黑**；**干净** ↔ **故障**。

## 2. 舞台：灰棚里的“无人乐队”

分镜中最关键的是乐队全景：深灰无缝摄影棚、圆形舞台、蓝色鼓组、橙色与蓝色电吉他、双层键盘、地面灯罐，**没有真人乐手**。

可读出的舞台规则：

| 元素 | 做法 |
|---|---|
| 背景 | 深灰无缝墙，几乎无纹理，靠灯光做层次 |
| 地面 | 深灰地胶，圆形舞台边缘有一圈细 LED |
| 乐器 | 像玩具/模型一样摆在台上，颜色高饱和、材质偏塑料/金属 |
| 人物 | 没有真人；乐器“自奏”，是超现实的核心 |
| 灯光 | 地面灯罐 + 可见光束，暖橙/粉/蓝点缀 |
| 镜头 | 低机位、长焦压缩、缓慢环绕，偶尔硬切 |
| 画幅 | 4:3，像旧 MV / 电视画面 |

EchoStage 几乎照搬了这套“**灰棚 + 玩具乐器 + 自奏**”的结构，但把乐器换成程序化建模，并加入“回声环”光环与更明确的声部颜色编码。

## 3. 2D / 3D 拼贴：手绘小人站在真实空间里

酒吧场景里，白色西装、黑色线稿的小人坐在真实照片/3D 背景前，胸口是彩色的故障器官。星空场景则把同一个小人放进银河背景，像一张被扫描进来的手绘图层。

这种“**2D 线稿角色 + 3D/实拍背景**”的拼贴，制造了“被复制出来的我”的不真实感。EchoStage 没有直接复刻角色，而是把拼贴感转译成：

- 3D 舞台 + 2D HTML 字卡 / HUD；
- 手绘感的粗体字与色差；
- 颗粒、扫描线、暗角，让渲染画面像印刷/录像。

## 4. 字卡：把歌词变成海报

MV 中穿插大量**全屏字卡**：黑底、巨大英文/日文字、荧光色、错位、重复、故障纹理。

特征：

- 字号极大，几乎撑满画面；
- 字体粗、手写/涂鸦感，带描边和错位；
- 荧光绿、紫、粉、蓝，和灰棚形成强对比；
- 出现时机是段落切换 / 鼓点重拍，而不是一直挂着。

EchoStage 的对应实现：

- `DECONSTRUCT / STEMS / COPY / ECHO` 四张字卡，对应 INTRO / VERSE / CHORUS / OUTRO；
- 粉/蓝双色错位阴影、斜切、1.55 秒闪现；
- 只在播放中段落切换时出现，避免遮挡舞台。

## 5. 镜头与剪辑

从 29 张分镜可以归纳出：

1. **4:3 画幅**，构图偏紧，乐器经常被切边。
2. **缓慢环绕**建立空间，随后**硬切**到特写/字卡。
3. 特写优先给**鼓组、吉他、键盘**，而不是人脸。
4. 黑场与字卡作为“呼吸”，把歌曲切成块。
5. 复制/重复：同一画面出现多个“我”，或同一乐器多次出现。

EchoStage 的导演系统把“段落”映射为镜头组：

- INTRO：广角慢环绕；
- VERSE：键盘 / 鼓 / 贝斯轮流；
- CHORUS：每 2 秒硬切，广角 → 鼓 → 吉他 → 主唱 → 键盘 → 俯拍；
- OUTRO：拉远、侧收。

## 6. 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 炭黑 | `#17181a` | 背景、字卡底 |
| 暖灰 | `#55565a` | 摄影棚墙面、地面 |
| 奶油 | `#f0e7d6` | 鼓皮、琴键、标题字 |
| 荧光粉 | `#ff4f8b` | 主强调、字卡、灯环 |
| 橙 | `#ff6b4a` | 鼓组/灯光、暖侧光 |
| 电蓝 | `#4d7cff` | 贝斯/冷侧光 |
| 黄铜 | `#d8b56b` | 镲片、金属件 |
| 薄荷 | `#79f2c0` | 键盘/数据 |

规则：**大面积低饱和 + 小面积高饱和**；一件乐器一个主色；灯光颜色不超过 3 种同时出现。
